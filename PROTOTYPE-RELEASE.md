# CrashAlert prototype 0.1.0

Android APK for reviewing the five-tab user interface, automatic local motion monitoring after rider setup, red self-check, Medical ID, location/sensor display, and seven-day/thirty-day on-device reports.

**This public debug APK is not connected to a cloud account. It does not automatically send SMS, call emergency services, or contact hospitals. It is not a validated safety device.** The Profile test screen never contacts anyone.

Install the `CrashAlert-prototype.apk` asset below on a physical Android device. If Android says it conflicts with a previous debug APK, uninstall the older one first; that removes locally saved profile, contacts and reports. The APK uses the runner's debug signing key and is meant only for demonstration. A future signed version requires a stable private signing key and its own release.

Source and current limitations: [README](https://github.com/CodeGunmay/CrashAlert#readme).
